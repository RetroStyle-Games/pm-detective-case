# 01 Розслідування

Здаєш у застосунку, у полі «Посилання або файл»: Google Doc/Sheet без входу або PDF/DOCX/XLSX. Ця папка — лише підказка; файли сюди класти не потрібно.

На сторінці «Здача справи» можна змінити здачу й додати необов’язкову «Нотатку для журі».

План / факт: чотири виробничі стадії (Concept 2D, Modeling + Texturing 3D, Render, Overpaint 2D) та окремий рядок Lead review / assembly. По рядках — дні й собівартість; унизу — загальні виручка, собівартість і маржа. Лід у собівартості, окремої виручки не має. Додай причини з доказами та точки втручання PM; на кожну — одну фразу клієнту англійською. До 2 сторінок.
