# Етап 1. Розслідування

Формат: один документ до 2 сторінок — Markdown, PDF, Word або Excel (план/факт можна окремим аркушем), або посилання на Google Doc/Sheet з доступом за лінком.

Усередині три частини:

1. **Таблиця «план / факт»**: по кожній із чотирьох стадій (Concept 2D, Modeling + Texturing 3D, Render, Overpaint 2D) скільки людино-днів планували і скільки витратили насправді; внизу в доларах виручка, собівартість і маржа, план і факт. Так, щоб було видно, де саме зникли гроші.
2. **Причини перевитрати**, кожна з доказом: цитата з листування або чату (дата, автор) чи рядок з логу годин. Причина без доказу не зараховується.
3. **Що PM мав зробити інакше**: у які дати і що саме; для кожної дати одна фраза англійською, яку треба було написати клієнту в той момент.

Матеріали для цього етапу: `../case/` і чати в застосунку.

Можна вписати розслідування прямо в цей README.md. Змінений README зараховується як робота.
