# Етап 4. Оцінка Christmas Edition

Порахуй Christmas своїм калькулятором з `../calculator/`, спираючись на досвід рескіну з `../reskin/`. Це пропозиція Jina перед переговорами на 05.

У таблиці (Excel, Google Sheets із доступом, CSV або Markdown) покажи:

| Що | Що пояснити |
|---|---|
| Пайплайн з AI | Яку стадію AI замінює або прискорює; не копіюй автоматично 2D → 3D → 2D |
| Дні | База без AI, витрати на генерації та ітерації, економія, ручні доробки, перевірка і резерв |
| Художники | Що лишається людям: ракурс, сітка, стиль, шари, правки; хто це робить |
| Економіка | Ціна клієнту, собівартість із лідом, маржа від виручки; цифри збігаються з калькулятором |
| Припущення | На чому ґрунтується економія; що виміряв у рескіні, а що ще треба перевірити |

Готові сцени клієнта й Halloween уже є. Не зараховуй їх повторне використання як економію від AI.
Після переговорів онови `estimate/` під домовленість із Jina; збережи початкову версію або поясни зміну цифр.
