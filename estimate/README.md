# 03 Оцінка

Справа 2021 року, але оцінюєш так, ніби робиш її сьогодні з AI-інструментами 2026; ставки й ростер — з матеріалів справи.

Здаєш у застосунку, у полі «Посилання або файл»: Google Doc/Sheet без входу або PDF/DOCX/XLSX. Ця папка — лише підказка; файли сюди класти не потрібно.

На сторінці «Здача справи» можна змінити здачу й додати необов’язкову «Нотатку для журі».
