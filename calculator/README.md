# Етап 4. Калькулятор ресурсів

Естимація є, тепер треба обрати команду, щоб маржа була вигідною.

У тебе є: твоя оцінка, список команди `calculator/data/roster.csv` (що означає кожна колонка — у README поруч) і ставки `case/08-rate-card.md`.

Зроби інструмент — таблицю, скрипт, вебсторінку, будь-що, що ми зможемо відкрити й запустити.

Обов'язково: він підбирає команду з ростера і рахує маржинальність — виручку, собівартість і маржу. Як саме — вирішуй сам(а).

Усе, що зверху, — плюс: наприклад, дедлайн 10.12 з урахуванням, хто коли вільний, або «що буде, якщо клієнт попросить знижку чи додасть роботи».

Для базової здачі: команда з ростера (хто, яка роль, скільки днів) і розрахунок виручки, собівартості й маржі. Необов'язкові доповнення: врахування доступності до 10.12, сценарії (знижка X%, доп. скоуп на N днів, дедлайн раніше на D днів), підтримка іншого ростера, опис обмежень («де бреше»).

Додай коротку інструкцію, як запустити. Запуск із папки `calculator/` має працювати з доданими даними; не посилайся на папки поза репозиторієм. Для Python на Windows вкажи команду `python -X utf8` з назвою твого файла.

Результат на твоїх даних — у файлі з result/результат у назві (.xlsx, .csv, .md або скрин/експорт) чи в розділі «Результат» README. Покажи виручку, собівартість і маржу. Один файл може містити інструмент і результат.

Оцінку із зупинки 03 можна покласти як CSV у `calculator/data/` і читати її калькулятором — переписувати дані вручну не потрібно.

Визначення раунду правок — у `case/08-rate-card.md`.

Де що здаєш — у [README репозиторію](../README.md#де-що-здаєш).
