# Дані для задачі із зірочкою «Калькулятор»

Усі дані навчальні.

## `christmas-tasks.csv`
Розбивка Christmas Edition на задачі. `days_min` / `days_max` — людино-дні при `speed_factor = 1.0`. `depends_on` — що має бути готове до старту задачі. Після T1 (концепт) і T8 (рендер) клієнт дає фідбек 1–2 робочих дні, це теж час у календарі.

## `roster.csv`
Хто доступний. `rate_per_day` — собівартість, $/людино-день. `quality_1_5` — наша внутрішня оцінка якості. `speed_factor` — у скільки разів реальний час людини відрізняється від оцінки (0.8 швидше, 1.3 повільніше). `w1…w4` — скільки робочих днів людина вільна в кожен тиждень.

Календар: W1 = 15–19.11, W2 = 22–26.11, W3 = 29.11–03.12, W4 = 06–10.12. Старт не раніше 15.11 (Jina обіцяла фінансове погодження до п'ятниці 12.11). Дедлайн, якщо не домовився інакше: 10.12.

## Ціна і правила
Rate card у `../../case/08-rate-card.md`: $300 за людино-день клієнту, лід у собівартості, два раунди правок у ціні, додатковий скоуп окремо.
